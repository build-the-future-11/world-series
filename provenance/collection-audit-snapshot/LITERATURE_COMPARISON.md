# Targeted literature and novelty comparison

Checked online 24 September 2026 against primary papers or author/publisher pages. Reading depth: abstracts and source metadata, with relevant method descriptions where available; this is a targeted comparison, not an exhaustive systematic review or proof of novelty. Judgments in the last column are audit inferences from these sources and local code.

| Project | Closest verified prior work | What is already established | Remaining project-specific contribution test |
|---|---|---|---|
| QLearn | [Celo2](https://arxiv.org/abs/2602.19142), [ELO](https://arxiv.org/abs/2607.06772) | Learned update rules, efficient meta-training and long-horizon/generalization evaluation are active prior contributions. | Resource-aware controller benefit must survive stronger optimizers, full cost and stability evaluation. Local Celo2 numbers cannot inherit its paper's wider conclusions. |
| Q-APEN | [CN-DPM](https://arxiv.org/abs/2001.00689) | Expansion-based neural experts for task-free continual learning already exist. | Demonstrate delayed-utility memory plus lifecycle beyond single-expert memory and qualified expansion controls; do not call threshold spawning Bayesian inference. |
| QWIPII | [Symmetry and Reduced Symmetry in Model Checking](https://www.nokia.com/bell-labs/publications-and-media/publications/symmetry-and-reduced-symmetry-in-model-checking-0/) | Quotienting and the problem of properties breaking symmetry are longstanding. | A newly useful verified-discovery/search mechanism, not only ordinary canonicalization and a known fixed-goal limitation. |
| WCODE | [Learning to Represent Programs with Graphs](https://arxiv.org/abs/1711.00740), [DreamCoder](https://arxiv.org/abs/2006.08381) | Graph program representations and neural-guided synthesis/library learning are established. | Isolate the proposed trained relational hierarchy under a common enumerator, verifier, semantic split and total budget. |
| WFIM | [A Primer on the Signature Method in Machine Learning](https://arxiv.org/abs/1603.03788) | Tensor/graded representations and compositional path features have a mature literature. | Useful finite-budget coordinate learning, with a nontrivial parameter effect. Local automorphism cancellation is established by the audit's direct proof, not attributed to this paper. |
| WFT | [Learning Laplacian Matrix in Smooth Graph Signal Representations](https://arxiv.org/abs/1406.7842) | Learning graph Laplacians from signals already exists. | Evaluate new symmetry/resolution constraints against identical operator learning; PSD and full-basis reconstruction are insufficient. |
| WPINN | [SINDy](https://arxiv.org/abs/1509.03580), [Weak SINDy](https://arxiv.org/abs/2005.04339) | Sparse discovery and weak-form noisy-data identification already exist. | Verify a distinct appropriate-structure benefit over qualified WSINDy, including failure/identifiability analysis. |
| CWLNN | [DiffPool](https://arxiv.org/abs/1806.08804) | Learned hierarchical graph representations predate the proposal. | Distinct sparse routing accuracy/cost tradeoff across graph families; fixed feature improvement does not validate a universal architecture. |
| Ultron | [RouteLLM](https://arxiv.org/abs/2406.18665) | Learned routing for cost/quality tradeoffs is established. | Verified heterogeneous research-capability selection with trustworthy external outcomes. RouteLLM is contextual prior art, not a numerically comparable DSL baseline. |

Additional current WPINN screening found [Tensor-Train Weak SINDy](https://arxiv.org/abs/2609.09434), posted September 2026. It studies high-dimensional weak discovery; it should enter a future full novelty review if scalability is claimed. Its existence is not evidence against the local proposal by itself.

No project currently has a substantiated novelty finding. This is different from concluding that every possible intended contribution is non-novel. A claim-specific full-paper comparison remains a closure dependency.
